SEAL BROWSER - BUILD THE IPHONE IPA WITH GITHUB ACTIONS

This package includes a GitHub Actions workflow that builds an UNSIGNED Seal Browser IPA on a GitHub-hosted Mac.
You can then use a sideloading app such as Sideloadly or AltStore to sign/install it with your own Apple ID.

EASIEST METHOD
1. Go to GitHub and create a new repository, for example: SealBrowser-iOS
2. Extract this ZIP on your Windows PC.
3. Upload ALL extracted files/folders into the root of the GitHub repository.
   Important: include the hidden .github folder.
4. Commit the files to the main branch.
5. Open the repository's Actions tab.
6. Open "Build Seal Browser IPA".
7. If it did not run automatically, choose "Run workflow".
8. Wait for the build to get a green checkmark.
9. Open that completed run.
10. Under Artifacts, download "SealBrowser-iPhone-IPA".
11. Extract that downloaded artifact ZIP. Inside is SealBrowser-unsigned.ipa.
12. Use Sideloadly or AltStore to sign/install that IPA onto your iPhone.

IMPORTANT
- The IPA generated by GitHub is intentionally unsigned. This is normal for sideloading.
- Apple still requires the app to be signed for YOUR device before iOS will launch it.
- With a free Apple ID, sideloaded apps normally need periodic re-signing according to Apple's current rules.
- Do not share your Apple ID password, signing certificates, or provisioning files with anyone.

WORKFLOW FILE
.github/workflows/build-ipa.yml

IPHONE REQUIREMENT
iOS 16 or later.
