Seal Browser for iPhone — Blue Mobile Edition

NEW IN THIS BUILD
- Open tabs are saved automatically.
- The selected tab is restored when Seal Browser launches again.
- Each tab restores its last webpage after the app is closed.
- Website cookies/local storage continue to use WKWebView's persistent data store.
- New blue glass-style iPhone interface.
- Bottom address/search bar designed for one-handed use.
- New tab switcher with tab cards and close controls.
- Loading progress bar and reload/stop control.
- Links that request a new window open in a new Seal Browser tab.

NOTE
WKWebView cannot preserve the full back/forward navigation stack after iOS terminates the app. Seal Browser restores each tab's current page, title, order, and selected tab.
