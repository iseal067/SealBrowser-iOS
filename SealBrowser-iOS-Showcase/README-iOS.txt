Seal Browser for iPhone — Showcase Edition

WHAT CHANGED
- Reworked the interface to feel like a real iOS browser instead of a neon concept mockup.
- Removed the heavy glow/gradient styling and generic marketing text.
- Uses native iOS materials, system typography and one consistent blue accent.
- Replaced the old generated-looking seal mascot icon with a simple flat Seal monogram.
- New Safari-style bottom browser controls with a compact address bar.
- Cleaner page title/host display when you are not editing the address.
- New overflow menu for New Tab, Reload/Stop and Copy Address.
- Tab switcher now captures real webpage previews when possible.
- Long-press a tab for Open Tab, Close Other Tabs and Close Tab.
- New tab page is intentionally simple: local greeting, date, search and quick links.

STILL INCLUDED
- Open tabs are saved automatically.
- Selected tab is restored when the app launches again.
- Each tab restores its last webpage after the app is closed.
- English Google searches with UK localisation.
- YouTube / YouTube Shorts WebKit media compatibility settings.
- Picture in Picture and inline video support where the website allows it.
- Links that request a new window open in a new Seal Browser tab.
- Persistent cookies and website storage through WKWebView's default data store.

NOTE
WKWebView cannot preserve the full back/forward navigation stack after iOS completely terminates the app. Seal Browser restores each tab's current page, title, order and selected tab.
