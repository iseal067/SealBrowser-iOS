Seal Browser for iPhone — Android v2 matched edition

This build intentionally matches the Samsung/Android v2 interface:
- black page chrome with #121214 bottom bar
- #1C1C1E address field and #0A84FF controls
- address/search bar at the bottom
- five-button navigation row: Back, Forward, New Tab, Tabs, Menu
- full-screen two-column tab switcher with live page snapshots
- matching tab-card dimensions, selected blue outline, and close controls
- matching minimal New Tab / Favourites page
- matching abstract blue Seal Browser icon

Preserved iPhone features:
- saved/restored tabs
- English / UK Google searches
- YouTube Shorts and inline HTML5 video support
- Picture in Picture and AirPlay support
- new-window links open in new tabs

Build it with the same GitHub iOS workflow you already use. No workflow changes are required if it searches for SealBrowser-iOS-Source*.zip or finds SealBrowser.xcodeproj automatically.
